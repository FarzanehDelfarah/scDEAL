## What this repository contains

This is my modified and extended version of the original scDEAL framework (OSU-BMBL). I adapted the code for my Master's thesis: *"Predicting Radiosensitivity and Radioresistance of Cancer Cells Using a Deep Neural Network"*

## My contributions

- Adapted the deep transfer learning framework from drug sensitivity prediction to **radiosensitivity prediction**
- Modified data preprocessing pipeline for radiation response data
- Trained and evaluated on [number] cancer cell line datasets
